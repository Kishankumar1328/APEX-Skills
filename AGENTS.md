# APEX AI-SDLC Instructions

Use the APEX skills in `skills/` for repeatable development and QA workflows.

- Use `developer-skill` for implementation, debugging, refactoring, security remediation, and review work.
- Use `testing-skill` for risk-based test planning, execution, defect reporting, and fix verification.
- Inspect the repository and relevant requirements before selecting commands or specialists.
- Select only the specialists required by the task and risk; do not invoke every specialist by default.
- Preserve user changes, report only executed evidence, and do not claim formal release approval.
- Use the seven test-result states: `PASSED`, `FAILED`, `BLOCKED`, `SKIPPED`, `NOT_RUN`, `FLAKY`, and `INCONCLUSIVE`.

Read the relevant `SKILL.md` before following a specialized workflow.
