# /develop

Invokes the APEX Developer Skill in the current workspace.

## Usage
```text
/develop [task description, bug report, or user story]
```

Orchestrates the 7 developer specialists with distinct responsibilities:
- `coding-agent` (feature authoring)
- `debugging-agent` (reproduction, root cause diagnosis, source code fix, and test verification)
- `unit-testing-agent` (hermetic unit test authoring & verification)
- `security-scan-agent` (vulnerability & dependency detection)
- `code-review-agent` (5-axis code review)
- `remediation-agent` (authorized security fixes)
- `refactoring-agent` (behavior-preserving structural cleanup)
