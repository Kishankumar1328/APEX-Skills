# Definition of Done (DoD)

A development or testing task is complete ONLY when all criteria below are satisfied:

1. **Requirements Satisfied:** Implemented behavior matches documented acceptance criteria.
2. **Hermetic Tests Green:** Unit and functional test suites executed fresh with 0 failures.
3. **Security Verified:** No hardcoded secrets; package audit shows no critical vulnerabilities.
4. **Code Reviewed:** Diff evaluated across correctness, readability, architecture, security, and performance.
5. **Zero Duplicate Artifacts:** No duplicate PRD, planning, or boilerplate documentation created.
6. **Evidence Documented:** Final report includes exact executed commands and observed output logs.
